🔄 System Flow

Architecture Pipeline:

Swagger → API → Kafka → Worker → SQL Server → API → UI


Step-by-Step:

  1. Send log via Swagger POST /api/LogPush
  2. API publishes message to Kafka topic
  3. Worker consumes from Kafka
  4. Worker stores logs in SQL Server
  5. API fetches logs from DB
  6. UI displays logs

Test Instructions:

  1. Open Swagger
  2. Execute POST /api/LogPush
  3. Wait 2–3 seconds
  4. Go Dashboard → Refresh
  5. Logs should appear
