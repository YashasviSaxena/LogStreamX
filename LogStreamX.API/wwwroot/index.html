🚀 End-to-End Project Flow


1️⃣ Client sends log → Swagger API
2️⃣ API receives request → /api/LogPush
3️⃣ Kafka publishes message → logs-topic
4️⃣ Worker Service consumes Kafka message
5️⃣ Data saved into SQL Server DB
6️⃣ UI fetches from → /api/logs
