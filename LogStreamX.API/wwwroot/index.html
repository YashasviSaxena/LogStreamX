End-to-End Flow (How it works)

1️⃣ Client → POST /api/LogPush (Swagger)
2️⃣ API → pushes message to Kafka topic
3️⃣ Kafka → stores event in log-stream
4️⃣ Worker Service → consumes Kafka messages
5️⃣ Worker → saves into SQL Server
6️⃣ UI → fetches /api/Logs every 5 seconds
7️⃣ Dashboard → shows real-time observability
